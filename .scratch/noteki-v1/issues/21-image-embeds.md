# 21: Image Embeds

**What to build:** `![[image.png]]` and `![](image.png)` show the image in the Note, at most as wide as the text. `![[file.pdf]]` is a link that opens the PDF.

**Blocked by:** 19 (Live preview of inline syntax), 03 (Images and PDFs in native views)

**Status:** ready-for-agent

- [ ] Image Embeds render inline, scaled to the text width
- [ ] The Embed's source appears when the cursor is on it
- [ ] A PDF Embed opens the PDF in its native view
- [ ] Missing images show their name as an Unresolved link
- [ ] Tested at Seam 2
