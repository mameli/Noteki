# Euler's identity

$$e^{i\pi} + 1 = 0$$

It follows from Euler's formula $e^{i\theta} = \cos\theta + i\sin\theta$, read from the Taylor series:

$$e^{x} = \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \cdots$$

Used in [[Maxwell's equations]] for plane waves, $\mathbf{E} = \mathbf{E}_0\, e^{i(\mathbf{k}\cdot\mathbf{r} - \omega t)}$.
